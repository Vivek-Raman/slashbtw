# Slash BTW

Barebones Electron application with React, Vite, TypeScript, Tailwind CSS v4, and shadcn/ui.

## Development

```bash
npm install
npm run dev
```

This starts the Vite development server and opens the Electron window.

## Production build

```bash
npm run build
npm start
```

## Add shadcn components

```bash
npx shadcn@latest add <component>
```
